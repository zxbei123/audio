# 📦 关于本仓库 / About This Repository

本仓库用于临时存放「生日贺卡网站」所需的**语音祝福与照片文件**，并通过 jsDelivr CDN 向贺卡页面提供访问。

This repository temporarily stores voice messages and photos used by a personal birthday-card website, delivered to the card page via the jsDelivr CDN.

---

## 📢 重要声明 / Important Notices

### 1. 本仓库是公开的 / This repository is public

- 本仓库为 **Public（公开）** 状态，这是 CDN 分发的技术前提。任何知道仓库地址的人都可以浏览、试听或下载其中的文件。
- This repository is intentionally public so the CDN can serve files. Anyone who knows the repository address can browse, play, or download its contents.

- 由于 CDN 缓存特性，已删除的文件仍可能在 jsDelivr 节点上残留**最多约 7 天**。
